# ДомРядом — аренда квартир и домов

Одностраничное приложение на Vue 3: объявления об аренде квартир и домов в
разных городах России. Данные берутся с публичных страниц Циан, проходят через
автоматический конвейер `браузер → HTML → JSON` и отдаются интерфейсу через API.
Справочник городов не захардкожен: он собирается из данных самого Циан, а город,
которого ещё нет в снимке, автоматически загружается при поиске.

## Что умеет приложение

- поиск по названию, подзаголовку, городу, району, метро, адресу и описанию;
- фильтры по городу, типу жилья (квартира/дом), цене, комнатности/спальням и району;
- сортировка по цене и площади, счётчик найденных объявлений;
- избранное с сохранением в `localStorage` и в базе после входа;
- история просмотренных объявлений;
- регистрация, вход и выход из аккаунта;
- подробная карточка с галереей, фактами и ссылкой на источник;
- пустые состояния и аккуратная обработка отсутствующих полей;
- фильтрация заведомо ошибочных цен (меньше 3 000 ₽/мес.) на этапе сборки и API;
- автоматическое обновление снимка данных при запуске, если он устарел.

## Стек

- Vue 3 (Composition API, `<script setup>`);
- Vite 8;
- Express 5 + встроенный `node:sqlite`;
- Python 3 + `lxml` для разбора HTML;
- Electron для автоматического получения страниц Циан;
- CSS без UI-фреймворков: яркий оранжевый, чёрные рамки, белый/чёрный текст.

## Быстрый запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`.

`npm run dev` поднимает API и Vite. При старте API проверяет
`src/data/listings.json`: если файла нет или он старше 6 часов, автоматически
обновляются уже собранные города (квартиры и дома). Никаких ручных команд на
каждую страницу не нужно. Прогресс виден в интерфейсе.

Если в поиске ввести город, которого ещё нет в снимке, сервер находит его в
справочнике Циан и сам загружает этот город в фоне. Например, «майкоп» не
требует правки кода или отдельной команды — приложение подтянет его данные.

Если город уже есть в снимке, но его HTML старше `CIAN_CITY_TTL_HOURS`
(по умолчанию 6 часов), поиск этого города сначала обновит только его, а потом
покажет результаты. Это работает и для 12, 18, 24 часов — достаточно поменять
`CIAN_CITY_TTL_HOURS`.

Продакшен-сборка:

```bash
npm run build
npm start
```

`npm start` отдаёт собранный `dist` и API на `http://127.0.0.1:3001`.

## Как работает автоматический сбор

```text
npm run dev
  └─ server/index.js
       ├─ проверяет src/data/listings.json
       ├─ parser/discover_cities.py читает справочник городов из HTML Циан
       ├─ если снимок устарел → parser/refresh.mjs
       │    ├─ parser/fetch_cities.cjs (Electron: нужные города × квартиры/дома)
       │    └─ parser/build_dataset.py (HTML → единый JSON)
       └─ GET /api/listings отдаёт готовый список
```

`parser/discover_cities.py` вытаскивает id и названия городов из встроенного
JSON Циан и пишет `parser/data/cities.json`. Поэтому города не перечисляются
в коде: Майкоп и любой другой город появляются в справочнике автоматически.
Файл можно пересобрать командой `npm run cities`.

`parser/fetch_cities.cjs` открывает настоящий браузер, проходит по выбранным
городам и сохраняет отрисованный HTML. Если Циан показывает капчу, её нужно
один раз пройти в открытом окне — это не обход защиты, а обычное подтверждение
пользователя. После этого сборщик сам продолжает остальные страницы.

По умолчанию обновляются города, которые уже есть в `parser/data`, а поиск
нового города запускает точечную загрузку через `/api/listings/ensure-city`.
Полный обход всего справочника (1121 город, это долго) можно запустить вручную:

```bash
npm run refresh:all
```

Ручной запуск конвейера по уже собранным городам (не требуется при обычном
`npm run dev`):

```bash
npm run refresh
```

Полезные переменные окружения:

```bash
ELECTRON_BIN=/путь/к/electron   # если Electron не найден автоматически
CIAN_CITY_IDS=4855              # загрузить конкретные города по id
CIAN_ONLY=Майкоп,Сочи           # ограничить города по названию
CIAN_ALL_CITIES=1               # обойти весь справочник городов
CIAN_SKIP_EXISTING=1            # не перекачивать уже сохранённые HTML
CIAN_WAIT_MS=15000              # пауза после открытия страницы
CIAN_HEADLESS=1                 # скрыть окно (challenge может не пройти)
CIAN_AUTO_REFRESH=0             # отключить автообновление на сервере
CIAN_REFRESH_TTL_MS=21600000    # срок жизни снимка, по умолчанию 6 часов
CIAN_CITY_TTL_HOURS=6           # обновлять отдельный город после 6/12/18/24 ч
```

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/listings` | список объявлений, время обновления и статус сборки |
| GET | `/api/listings/status` | статус снимка и сборщика |
| GET | `/api/cities?q=майкоп` | поиск города в автоматическом справочнике Циан |
| POST | `/api/listings/ensure-city` | загрузить новый или обновить устаревший город |
| POST | `/api/listings/refresh` | запустить сбор; `{ "force": true }` — принудительно, `{ "allCities": true }` — весь справочник |
| POST | `/api/auth/register` | регистрация |
| POST | `/api/auth/login` | вход |
| POST | `/api/auth/logout` | выход |
| GET | `/api/auth/me` | текущий пользователь |
| GET/PUT/DELETE | `/api/me/favorites...` | избранное |
| GET/POST/DELETE | `/api/me/viewed...` | просмотренные |

Пароли хранятся как scrypt-хеши, сессии — случайные bearer-токены. База
SQLite создаётся в `server/data/app.db`; для тестов можно задать `DB_PATH`.

## Проверки

```bash
npm run build
python3 parser/parse_cian.py parser/fixtures/sample.html -o /tmp/fixture.json
```

`parser/fixtures/sample.html` — синтетическая страница с тремя объявлениями, у
третьего нет цены, фото и ссылки. Это проверяет устойчивость интерфейса к
неполным данным.

## Ограничения

- Циан может менять разметку — тогда нужно обновлять XPath/селекторы.
- Фотографии загружаются с CDN Циан; без сети показывается placeholder.
- Сбор занимает несколько минут: один браузер последовательно обходит страницы.
- Если Циан просит капчу, её проходит человек в открытом окне браузера.
- Проект не аффилирован с Циан; уважайте правила сайта и не создавайте
  чрезмерную нагрузку.
